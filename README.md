# cdsl-llama

`cdsl-llama` is a repository for experiments, tooling, and research workflows related to LLaMA-based large language models.

## Overview

This project is intended to organize code, notes, and supporting materials for working with LLaMA-family models. It can be used for model experimentation, local inference workflows, prompt testing, evaluation, and related development tasks.

## Goals

- Build and document reusable LLaMA-based workflows
- Manage experiments and evaluation notes in a reproducible way
- Collect utilities for inference, testing, and model comparison
- Keep project materials organized for future development

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Yuzki/cdsl_llama.git
cd cdsl_llama
```

Install the dependencies required by the scripts or notebooks you plan to run. Detailed setup instructions will be added as the project structure becomes more defined.
